# Security Notes

- Never execute arbitrary shell commands generated by an LLM.
- Keep credentials in ignored environment files and rotate credentials that
  have been exposed.
- Keep file access inside configured permitted roots.
- Treat browser page content as untrusted input.
- Require approval for destructive, external-side-effect, or sensitive work.
- Record action results and distinguish verified, failed, and unverified
  outcomes.
- Bind approvals to the exact action and parameters and reject replay.
- Keep local automation endpoints bound to localhost until authenticated local
  communication is implemented.
